# Списки покупок

Официальные установочные сборки Android и история изменений.

[Скачать последнюю версию](https://github.com/renat-zinatulin/shopping-list-releases/releases/latest)

Установите APK из раздела Assets выбранного релиза. Новые версии устанавливаются поверх предыдущих с сохранением данных. Android 8.0 и новее.

Начиная с версии 0.3.13 обновления также доступны внутри приложения: Настройки → О приложении → пять последовательных нажатий на номер версии → Лаборатория → Обновление.

Этот репозиторий содержит только информацию о приложении и готовые выпуски. Исходный код и ключи подписи здесь не публикуются. Текущие APK являются тестовыми debug-сборками; ограничения проверки указаны в описании каждого выпуска.
